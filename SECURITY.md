# Security Policy

Do not post credentials, tokens, personal information, or exploit details in public issues or pull requests.

For a vulnerability, use GitHub's private vulnerability reporting feature if this repository has it enabled. Otherwise contact the maintainer privately.

MetroForge is a browser-based game. Do not commit local secrets, `.env` files, private keys, or real user data. Keys included in browser JavaScript are public by design; confidential API keys must be used only from a protected server. Revoke or rotate any leaked credentials rather than simply deleting them from source.
